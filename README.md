
**Wordownik** is a lightweight Python desktop application built with **Tkinter**. It was created primarily as an experimental project to explore GUI (Graphical User Interface) development in Python. The app allows you to manipulate and analyze text quickly without the need for a heavy, full-fledged text editing program.

## Features

- **Change a word:** Quickly find and replace specific words within your text.
- **Count the words:** Instantly calculate the total number of words.

## Technologies Used

- **Python 3** - **Tkinter** (Standard Python interface to the Tcl/Tk GUI toolkit)

## Project Purpose

This repository serves as a practical sandbox for learning Tkinter. It focuses on handling user input, basic text processing, and building interactive desktop applications from scratch.
